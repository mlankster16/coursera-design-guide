Learning Assets

Choosing the right Learning Asset

Once you’ve planned a Module’s learning path, you and your Learning Experience Designer can begin developing the Videos, Readings, Assessments, and other Learning Assets that support it. Start from what learners need at each step, then pick the format that fits.

Learning Assets available in Coursera

Video

A planned audiovisual asset that may combine an instructor’s presence or narration with slides, demonstrations, screen recordings, interviews, animation, or other visuals.

Use it when

Seeing or hearing something adds value: an introduction, explanation, demonstration, story, expert perspective, or model of how someone approaches a task.

In the Module 2 example

Think Aloud: Inspecting a Sample Dataset models how an expert compares a dataset with a business question.

Reading

A short page that introduces a file or external resource, or a more developed experience combining written explanation, examples, graphics, code, media, and links.

Use it when

Learners need time to examine information closely, follow instructions, revisit important material, or use a resource during another part of the Course.

In the Module 2 example

Data Fitness Criteria and Checklist gives learners a reference they use in the model, practice, and assessment.

Explore the Reading guide →

Assessments

Graded or ungraded questions that allow learners to practice, receive pre-determined feedback, or demonstrate what they have learned.

Use it when

Learners need to check their understanding, prepare for independent work, or demonstrate the Module objectives.

In the Module 2 example

Three ungraded practice checks build toward the auto-graded Data Fitness Review.

Coach Dialogue

An AI-powered conversation that responds to a learner’s ideas and choices.

Use it when

Learners would benefit from explaining their reasoning, considering alternatives, reflecting, or receiving personalized guidance.

Coach Role Play

Pilot

An AI-powered activity in which learners practice a conversation with a simulated persona.

Use it when

Learners need to practice an interpersonal or job-related skill, such as coaching, interviewing, negotiating, or responding to a difficult situation.

Our team hasn’t fully tested this tool at Duke yet. If you’re interested, let your CTL team know early so we can plan it together as a pilot.

Interactive Plugin

A Coursera feature that can embed a compatible external webpage, tool, or interactive experience that already exists and is hosted outside the Course.

Use it when

Approved external content supports the learning and embedding it gives learners a more connected way to view or interact with it.

Coursera Lab

A configured, in-browser workspace where learners can use code, data, software, or other technical tools.

Use it when

Learners need hands-on experience in a technical environment without extensive setup on their own devices.

Programming Assignment

Code-based tasks that allow learners to write, modify, debug, or evaluate a program and receive feedback on their work.

Use it when

Writing or working with code is part of the capability learners need to develop or demonstrate.
