The destination

Module 2: Identifying and Evaluating Business Data

By the end of this Module, learners will be able to:

  1. Identify the data needed to investigate a business question.
  2. Evaluate an available dataset for relevance, completeness, and basic quality concerns.
  3. Document limitations that could affect the proposed analysis.

The final task: Data Fitness Review

Evaluate whether an available dataset is suitable for addressing a business question and document concerns that could affect the proposed analysis.

Choosing Learning Assets to support your Module objectives

The learning path for Module 2: Identifying and Evaluating Business Data establishes what learners need to experience: an introduction to the evaluation criteria, a model of expert reasoning, supported practice with feedback, and an opportunity to complete the Data Fitness Review independently.

The next step is to organize those experiences into Lessons and select the Coursera Learning Assets that will support them.

Mapping your own Module

Start with what learners need to experience, then choose the asset

  1. Name each step first

    It helps to fill in the learning path column before picking formats, so each row describes what that step does for learners.

  2. Match the asset to the purpose

    Videos suit explaining and modeling, Readings suit reference material, and ungraded assessments or activities suit practice with feedback.

  3. End with the final task

    The last row is usually the graded assessment, where learners demonstrate the Module objectives.
